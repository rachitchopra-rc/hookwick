# ⚡ Hookwick — AI Coach for Short-Video Creators

Hookwick is an AI retention and hook coaching dashboard for Indian short-video creators (YouTube Shorts & Instagram Reels).

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
```

---

## 🌐 Deploy to Vercel or Netlify

### One-Click Vercel Deploy:
1. Push this repository to your GitHub account.
2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Select your GitHub repository and click **Deploy**.
